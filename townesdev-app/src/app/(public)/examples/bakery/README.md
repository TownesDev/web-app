# Sweet Sunrise Bakery - Portfolio Example

This is a demo website showcasing a professional small business website for a fictional bakery.

## Features

- **Mobile-responsive design** - Looks great on all devices
- **Multi-page layout** - Home, About, Menu, and Contact sections
- **Contact form** - Simple contact form for customer inquiries
- **Menu/product showcase** - Organized display of breads, pastries, and custom cakes
- **Google Maps integration** - Placeholder for map location

## Design

- Warm color scheme using amber and orange tones
- Clean, professional typography
- Inviting hero section with clear CTAs
- Grid-based menu layout for easy scanning
- Social media integration (Facebook, Instagram)

## Live Demo

Visit `/examples/bakery` to see the live demo.

## Technology

- Next.js 15 with TypeScript
- Tailwind CSS for styling
- Lucide React for icons
- Server-side rendering for optimal performance

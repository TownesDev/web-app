# The Midnight Collective - Portfolio Example

This is a demo website showcasing a professional musician/band website for a fictional alternative rock band.

## Features

- **Modern dark design** - Sleek, atmospheric design that matches the band's aesthetic
- **Music player mockup** - Placeholder for Spotify/Bandcamp/YouTube integration
- **Tour dates section** - Interactive tour schedule with ticket status
- **Social media links** - Integration with all major platforms
- **Newsletter signup** - Email collection for fan updates
- **Band member profiles** - Meet the band section

## Design

- Dark theme with purple and pink accent gradients
- Modern, engaging typography
- Prominent hero section with social links
- Interactive track listing
- Organized tour date display with status indicators

## Live Demo

Visit `/examples/musician` to see the live demo.

## Technology

- Next.js 15 with TypeScript
- Tailwind CSS for styling
- Lucide React for icons
- Server-side rendering for optimal performance

## Business Type

Perfect for:
- Musicians (solo artists)
- Bands
- DJs
- Music producers
- Podcasters
- Performance artists

## Sections

1. **Hero** - Eye-catching introduction with branding
2. **Music** - Featured album, track list, and music player mockup
3. **Tour Dates** - Complete schedule with ticket availability
4. **About** - Band member profiles and story
5. **Contact** - Booking information and contact form

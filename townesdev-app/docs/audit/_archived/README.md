# Archived Audits

This folder contains completed audit documents that are no longer actively referenced but preserved for historical record.

## Contents

- **docs-audit.md** - Initial documentation audit (Oct 2025)
- **refs-cleanup-analysis.md** - Analysis of refs folder cleanup
- **refs-folder-migration.md** - Migration plan for refs folder content

## Archive Policy

Documents are moved here when:

- The audit has been completed and addressed
- The information is no longer current but worth preserving
- The document is superseded by newer versions

Active audits remain in the parent `audit/` folder.
